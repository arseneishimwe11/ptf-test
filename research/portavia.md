# Portavia — portavia.framer.website

**Positioning:** free portfolio template by oldshen; "modern & minimal design
built to showcase portfolios with clarity, elegance, and creative focus."

## Palette & type
- Quiet, gallery-like neutrals; project imagery carries the color *(reported
  "clarity, elegance")*.

## Layout & rhythm
- **Modular project sections**: case studies, featured works, and experiments
  each get a different card/layout treatment instead of one uniform grid
  *(reported "flexible project sections… with modular layouts")*.
- Dedicated Featured Projects page — projects treated as first-class objects.

## Motion & interaction
- Understated reveals; elegance over spectacle *(reported tone)*.

## What we take
- Non-uniform work presentation: our Selected Work alternates full-width
  feature cards with paired half-width cards, so 5 projects read as a curated
  sequence, not a database dump.
- Per-project accent color pulled into the card's placeholder gradient — the
  "imagery carries the color" idea, achievable with generated assets.

## What we skip
- Separate projects page.
